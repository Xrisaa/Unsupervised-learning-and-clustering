# Unsupervised-learning-and-clustering
# How Much Structure Can You Find Without Labels?

This project investigates whether meaningful groups can be discovered in a dataset of wheat kernels without using their known variety labels. The Seeds dataset contains measurements of 210 wheat kernels, and the goal is to explore whether these measurements form distinct groups that could correspond to different wheat varieties.
The main question is how much of the real class structure can be discovered using clustering alone, before looking at the true labels. The analysis therefore focuses on discovering the structure present in the measurements and then comparing the resulting clusters with the actual wheat varieties. 
(The code was run in Google Colab)
